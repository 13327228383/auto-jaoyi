AI 驱动的智能量化交易引擎探索版：基于**行情自适应的多资产 ETF 动量轮动**策略，可回测、可实盘（同花顺客户端自动下单）。

## 特性

- **多资产 ETF 动量轮动**：沪深300 / 中证500 / 创业板 / 黄金 / 纳指 / 国债 + 标普500（7 只低成本高流动 ETF）
- **全局风险-off 保护**：美股熊市、A股熊市+黄金避险确认、双熊等跨资产联动触发 → 切换防御资产（黄金 518880）
- **防御资产自身动量门 + 迟滞带**：风险-off 时防御资产动量转负→空仓等待；零轴抖仓抑制
- **S/R 支撑阻力动态止损 + 跟踪止损 + 入场过滤**：随价创新高上移止损、锁利润、不追高
- **单日亏损熔断（盘中即时触发）**：当日组合亏损超阈值 → 转防御，回测验证盘中触发优于尾盘
- **同花顺客户端自动下单**：win32 动线自动化、委托确认、验证码自动识别、持仓双向对账

## 技术栈

- Python 3.9 / Playwright / pytest
- 数据源全部免费（akshare / sina / baostock），无付费接口、无 AI token 消耗
- 64-bit Python 负责策略决策；32-bit Python 驱动同花顺（32位）GUI 执行，指令文件通信
- Chrome 双击本地页面解锁

## 快速开始

```bash
# 1) 复制配置模板并填入你自己的券商账号密码
cp config.example.ini config.ini

# 2) 安装依赖
pip install -r requirements_free.txt

# 3) （研究用）运行回测
python research/backtest_daily_halt.py

# 4) （实盘用）启动主程序
start_auto.bat
```

> **请勿直接使用本仓库的 `config.ini` —— 真实配置已通过 `.gitignore` 排除并仅以脱敏模板 `config.example.ini` 提供。**

## 回测方法与诚实性说明

- 所有回测使用**真实历史行情**（akshare/sina），接口、手续费、换手成本均如实计入。
- 报告同时给出**全期与样本外（2021+）**两类指标，避免只看牛市区间的虚高收益。
- 部分高收益高度依赖 2021 年后黄金/A 股上行周期，**方向可信，绝对值请勿当真实预期**。
- 回测 ≠ 实盘；实盘受滑点、流动性、偶发异常影响，务必小额验证后再考虑实盘。
